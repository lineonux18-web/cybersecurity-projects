# Password Strength Analyzer

## Description
A Python-based tool that evaluates the strength of user passwords based on multiple security criteria.

## Features
- Checks password length
- Detects uppercase letters
- Detects numbers
- Detects special characters
- Provides strength rating: Weak / Medium / Strong
- Suggests improvements for weak passwords

## Technologies Used
- Python

## What I Learned
- Input validation techniques
- Basic security practices for password strength
- Writing conditional logic for real-world use cases
