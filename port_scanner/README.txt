# Port Scanner

## Description
A multi-threaded Python port scanner that identifies open ports on a target system and maps them to common services.

## Features
- Scans ports from 1 to 10000
- Detects open ports using TCP connections
- Multi-threaded for faster performance
- Identifies common services (HTTP, SSH, etc.)

## Technologies Used
- Python
- Socket programming
- Threading

## What I Learned
- How network ports work
- Basics of TCP connections
- How port scanning tools like Nmap operate
- Performance improvement using multi-threading

## Ethical Note
This tool is intended for educational purposes and should only be used on systems you own or have permission to test.
